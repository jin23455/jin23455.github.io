# 高雄市建築地標介紹網站

高雄市重要建築地標的介紹網站，包含：

- 高雄85大樓
- 高雄流行音樂中心
- 衛武營國家藝術文化中心
- 高雄展覽館

## 檔案結構

```
index.html       - 首頁（地標總覽）
1st.html         - 高雄85大樓
2nd.html         - 高雄流行音樂中心
3rd.html         - 衛武營國家藝術文化中心
4th.html         - 高雄展覽館
images/          - 圖片資料夾
README.md        - 本文件
```

## 功能

- 首頁以卡片式並排呈現各地標的圖片與介紹
- 點擊按鈕可進入各景點的詳細介紹頁面
- 詳細頁面採用圖文並排佈局
